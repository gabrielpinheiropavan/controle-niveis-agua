
# Controle de Níveis de Água

## Descrição
Projeto desenvolvido em Python para simular o monitoramento dos níveis de água de um reservatório.

O sistema utiliza a biblioteca Colorama para exibir mensagens coloridas no terminal, facilitando a identificação de cada situação.

## Níveis monitorados

| Nível | Situação | Cor |
|---|---|---|
| 1 | Muito baixo (Crítico) | Vermelho |
| 2 | Baixo | Amarelo |
| 3 | Médio | Verde |
| 4 | Alto | Ciano |
| 5 | Muito alto (Alerta) | Azul |

## Tecnologias utilizadas
- Python
- Colorama

## Como executar

1. Instale a biblioteca:

   pip install colorama

2. Execute o programa:

   python app.py

## Objetivo
Praticar conceitos de listas, funções, estruturas condicionais e utilização de bibliotecas em Python.
